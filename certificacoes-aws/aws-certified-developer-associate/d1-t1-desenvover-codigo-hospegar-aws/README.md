### OBJETIVOS DO EXAME AWS ABORDADOS NESTE TÓPICO
- [ ] Domínio de Conteúdo 1: Desenvolvimento com Serviços AWS
  - [ ] Tarefa 1: Desenvolver código para aplicações hospedadas na AWS
    - Aqui temos 13 Habilidades (Skills):
      - [ ] Habilidade (Skill): Descrever padrões arquitetônicos (por exemplo, orientado a eventos, microsserviços, monolítico, coreografia, orquestração, fanout)
      - [ ] Habilidade (Skill): Descrever as diferenças entre conceitos com estado e sem estado
      - [ ] Habilidade (Skill): Descrever as diferenças entre componentes fortemente acoplados e fracamente acoplados
      - [ ] Habilidade (Skill): Descrever as diferenças entre padrões síncronos e assíncronos
      - [ ] Habilidade (Skill): Criar aplicações tolerantes a falhas e resilientes em uma linguagem de programação (por exemplo, Java, C#, Python, JavaScript, TypeScript, Go)
      - [ ] Habilidade (Skill): Criar, estender e manter APIs (por exemplo, transformações de resposta/requisição, aplicação de regras de validação, sobrescrita de códigos de status)
      - [ ] Habilidade (Skill): Escrever e executar testes unitários em ambientes de desenvolvimento (por exemplo, usando AWS SAM)
      - [ ] Habilidade (Skill): Escrever código para usar serviços de mensagens
      - [ ] Habilidade (Skill): Escrever código que interaja com os serviços da AWS usando APIs e SDKs da AWS
      - [ ] Habilidade (Skill): Lidar com dados de streaming usando serviços da AWS
      - [ ] Habilidade (Skill): Usar o Amazon Q Developer para auxiliar no desenvolvimento
      - [ ] Habilidade (Skill): Usar o Amazon EventBridge para implementar padrões orientados a eventos
      - [ ] Habilidade (Skill): Implementar código de aplicação resiliente para integrações com serviços de terceiros (por exemplo, lógica de repetição, disjuntores, padrões de tratamento de erros)
